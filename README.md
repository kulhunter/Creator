## 🌟 ¿Qué es CreatorOS?
**CreatorOS** es una aplicación web y sistema integral diseñado para creadores de contenido, agencias y empresas que buscan dominar el tráfico orgánico, la retención en video vertical y el posicionamiento en motores de búsqueda de IA (**ChatGPT Search, Perplexity, Google Gemini**).

Sintetiza las metodologías de los mayores referentes mundiales (**Alex Hormozi, MrBeast & Paddy Galloway, Dan Koe, GaryVee, Jenny Hoyos, Hanah Franklin & Alef Marqs**) con un stack técnico de herramientas open-source de GitHub.

---

## ✨ Características Principales

1. **🎬 Explorador de los 32 Formatos Creativos:**
   - Plantillas validadas de puesta en escena (Desk POV cenital, Pantalla Dividida A/B, Diálogo de Doble Personaje, Telepatía, Pizarra, Metáforas físicas).
   - Guiones segundo a segundo con efectos de sonido (SFX) y 1-clic para copiar.

2. **⚡ Generador de Hooks Magnéticos (50+ Fórmulas):**
   - Personalizador en vivo de Nicho, Error, Meta y Plazo.
   - Presets para E-commerce, B2B, Cursos Online y Fitness.

3. **📝 Constructor Inteligente de Guiones en 3 Columnas:**
   - Fórmulas PAS (Problema-Agitación-Solución), IHC (Impacto-Historia-Conexión), AIDA y Ele-Eu-Você-Futuro.
   - Exportación directa en Markdown (`.md`) y portapapeles.

4. **🤖 Auditoría GEO (Generative Engine Optimization):**
   - Calculadora y checklist interactivo para asegurar que ChatGPT y Perplexity citen tu marca como autoridad canónica.

5. **🛠️ Suite de Herramientas Open-Source (GitHub):**
   - **Postiz** (`gitroomhq/postiz-app`): Programador omnicanal libre con IA.
   - **Faster-Whisper** (`SYSTRAN/faster-whisper`): Transcripción y subtitulado ultra-rápido.
   - **Auto-Editor** (`WyattBlue/auto-editor`): Poda automática de silencios y respiraciones.
   - **VideoLingo** (`Huanshere/VideoLingo`): Doblaje y traducción de videos con clonación de voz.
   - **Remotion** (`remotion-dev/remotion`): Animaciones y videos generados con código React.

6. **🏛️ Bóveda Reconstruida de Hanah Franklin & Alef Marqs:**
   - Mapa completo de 5 módulos y lecciones desglosadas.
   - Veredicto forense y prompt maestro de IA ("SOFIA").

## 🚀 Inicio Rápido Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/kulhunter/Creator.git
cd Creator

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

---

## 📦 Construcción para Producción

```bash
npm run build
```
Los archivos estáticos optimizados se generarán en la carpeta `dist/`, listos para GitHub Pages, Vercel o Netlify.
